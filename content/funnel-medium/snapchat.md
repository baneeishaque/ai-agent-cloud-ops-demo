# Snapchat — Spotlight script

One ~35-second vertical script. Fast cuts, burned-in captions, hook in the first second.

## Script

| Time      | Visual                                                       | Caption / VO                                                                 |
| --------- | ------------------------------------------------------------ | ---------------------------------------------------------------------------- |
| 0:00–0:03 | Airport, laptop carried half-open                             | "POV: your agent sleeps when your laptop does"                               |
| 0:03–0:08 | Lid closing in slow motion; screen fades                     | "Lid close → sleep. Sleep → no network. Network gone → agent paused."        |
| 0:08–0:13 | Split screen: laptop vs. cloud instance                      | "So I moved it off the laptop. Cloud instance. Never sleeps."                |
| 0:13–0:19 | Phone screen: WhatsApp thread with alerts and the 08:00 report | "WhatsApp is the control plane. Tasks out, alerts and the morning report in." |
| 0:19–0:25 | File path on the instance console                            | "Every run saves a log file. Chat = notification. File = proof."             |
| 0:25–0:30 | Text card: "Send a report even if there are no issues."      | "The clause that matters most: report even when nothing happened."           |
| 0:30–0:35 | End card: article title + repo                               | "Full system design — link in bio. 🔗"                                       |

## Notes

- Voice-over optional; captions carry the story (most Spotlight viewing is muted).
- Keep the laptop-lid shot first — it is the scroll-stopper.
- Do not show real customer or pricing data on screen; use the article's illustrative example.
